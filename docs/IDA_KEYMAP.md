# Raccourcis clavier IDA

Réglez `pileOuFace.keymap` sur `ida` pour activer ces touches dans les vues **Désassemblage** et **Décompilation** du hub :

| Touche | Action |
| --- | --- |
| `N` | Renommer l’adresse ou la fonction active |
| `X` | Afficher les références vers l’adresse active |
| `;` | Commenter l’adresse ou la fonction active |
| `G` | Aller à une adresse ou un symbole |

Le réglage vaut `default` par défaut. Le mode IDA ne capture aucune touche hors des deux vues, ni pendant la saisie dans un champ, une liste ou une zone éditable. Les changements de réglage sont appliqués au hub ouvert sans rechargement.

Actions candidates pour une prochaine itération : `Esc` (retour), `Space` (bascule graphe/texte), `F5` (décompiler) et les variantes de xrefs sortantes.
